# outdoor_webcam

商用電源や Wi-Fi がないキャンプ場に設置する、低頻度起動・SIM 通信型の屋外監視 Web カメラの設計ドキュメントとプログラムを管理するリポジトリです。

## 想定要件

- キャンプ場監視用途の屋外 Web カメラ
- オフグリッド運用（商用電源なし）
- 電源・電池交換をなるべく少なくする
- Wi-Fi は使わず、SIM による LTE/4G 通信を使う
- 1 日 1 回だけ起動して撮影・送信する
- 撮影した写真を AWS S3 に格納する
- 撮影時に Slack へ通知する

## 初期方針

1. **消費電力を最優先**し、通常時はマイコン・通信モジュール・カメラを完全停止または deep sleep にする。
2. **1 日 1 回の短時間ジョブ**として、起床 → 撮影 → S3 アップロード → Slack 通知 → 電源断/スリープを実行する。
3. **クラウド連携は段階的に検証**し、最初は開発ボードでプロトタイプを作り、その後に専用基板・屋外筐体へ進める。
4. **ハードウェア選定は未確定**とし、通信エリア、消費電力、耐候性、入手性、国内利用条件を確認して決定する。

## 開発フェーズ

| フェーズ | 目的 | 成果物 |
| --- | --- | --- |
| 0. 要件整理 | 画質、設置場所、通信頻度、運用期間を確定 | 要件定義、電力予算、通信量見積もり |
| 1. 部品調査 | マイコン、通信、カメラ、ストレージ、電源、筐体を比較 | パーツ選定表、概算 BOM |
| 2. PoC | 開発ボードで撮影・送信・通知を実証 | PoC ファームウェア、AWS/Slack 設定 |
| 3. 低消費電力化 | deep sleep、電源制御、再送制御を実装 | 消費電流測定結果、電池寿命見積もり |
| 4. 屋外試験 | 防水、防塵、温度、通信品質を検証 | 屋外試験ログ、改善タスク |
| 5. 運用設計 | 電池交換、死活監視、障害復旧を整備 | 運用手順、保守チェックリスト |

## 注意事項

- SIM/LTE モジュールは、利用国・通信キャリア・技適/認証・アンテナ条件を確認してから採用します。
- バッテリー、太陽光パネル、充電回路は屋外安全性を重視し、過充電・過放電・温度保護を必須条件にします。
- AWS 認証情報や Slack Webhook URL などの秘密情報はリポジトリへコミットしません。
