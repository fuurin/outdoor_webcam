# 必要タスク一覧

## タスク管理方針

- タスクはフェーズごとに管理する。
- ハードウェア、ファームウェア、クラウド、運用を分けて進める。
- 各フェーズの終了条件を明確にし、実測値を残す。

## フェーズ 0: 要件整理

- [ ] 設置場所を決める。
- [ ] 監視対象、必要画角、設置高さ、撮影方向を決める。
- [ ] 1 日の撮影時刻を決める。
- [ ] 夜間撮影の要否を決める。
- [ ] 画像の必要解像度、圧縮率、許容ファイルサイズを決める。
- [ ] 目標バッテリー交換間隔を決める。
- [ ] ソーラー充電を使うか決める。
- [ ] 盗難、いたずら、動物、積雪、結露への対策要否を整理する。

## フェーズ 1: 現地調査

- [ ] 設置候補地で LTE キャリアごとの電波強度を測定する。
- [ ] 日照条件を確認する。
- [ ] 防水筐体とアンテナの設置位置を確認する。
- [ ] 冬季/夏季の温度範囲を確認する。
- [ ] 管理者が電池交換できる頻度を確認する。

## フェーズ 2: パーツ選定

- [ ] マイコン/SBC 候補を比較する。
- [ ] LTE/4G モジュール候補を比較する。
- [ ] SIM 契約候補を比較する。
- [ ] カメラモジュール候補を比較する。
- [ ] バッテリー候補を比較する。
- [ ] ソーラー充電回路候補を比較する。
- [ ] 電源制御 IC / RTC / MOSFET 構成を比較する。
- [ ] 防水筐体、ケーブルグランド、アンテナを比較する。
- [ ] 初期 BOM と概算費用を作成する。

## フェーズ 3: クラウド設計

- [ ] S3 バケット命名規則を決める。
- [ ] S3 オブジェクトキー形式を決める。
- [ ] IAM 権限を最小化する。
- [ ] 端末認証方式を決める。
- [ ] Slack 通知方式を決める。
- [ ] Lambda を使う場合のイベントフローを決める。
- [ ] エラー通知と死活監視方法を決める。
- [ ] 秘密情報管理方法を決める。

## フェーズ 4: ファームウェア PoC

- [ ] 起床処理を実装する。
- [ ] カメラ初期化と撮影処理を実装する。
- [ ] LTE モジュール初期化と接続処理を実装する。
- [ ] 時刻同期処理を実装する。
- [ ] ローカル保存と保存完了確認を実装する。
- [ ] 未送信ファイルのキュー管理を実装する。
- [ ] S3 アップロード処理を実装する。
- [ ] Slack 通知または AWS 側通知トリガーを実装する。
- [ ] 失敗時の再試行・次回送信処理を実装する。
- [ ] ローカル保存データの容量上限、世代管理、現地回収手順を決める。
- [ ] deep sleep / 電源断処理を実装する。

## フェーズ 5: 電力測定

- [ ] 待機時電流を測定する。
- [ ] 起動時ピーク電流を測定する。
- [ ] 撮影中電流を測定する。
- [ ] LTE 接続中電流を測定する。
- [ ] アップロード中電流を測定する。
- [ ] 1 サイクルあたりの消費電力量を算出する。
- [ ] 目標運用期間に必要なバッテリー容量を算出する。
- [ ] 電波弱環境での消費増加を測定する。

## フェーズ 6: 屋外試験

- [ ] 防水筐体に収めて短期屋外試験を行う。
- [ ] 結露の有無を確認する。
- [ ] 画像の白飛び、逆光、夜間品質を確認する。
- [ ] LTE 接続失敗率を確認する。
- [ ] ソーラー充電量を確認する。
- [ ] バッテリー電圧低下時の動作を確認する。
- [ ] ログから改善点を洗い出す。

## フェーズ 7: 運用設計

- [ ] 電池交換手順を作成する。
- [ ] SIM 交換手順を作成する。
- [ ] 故障時の切り分け手順を作成する。
- [ ] S3 ライフサイクルルールを設定する。
- [ ] Slack 通知のメッセージ形式を確定する。
- [ ] 端末 ID と設置場所の管理方法を決める。
- [ ] 定期点検チェックリストを作成する。

## リスクと対策

| リスク | 影響 | 対策 |
| --- | --- | --- |
| LTE 電波が弱い | 接続時間増加、電池消費増加、送信失敗 | キャリア比較、外部アンテナ、設置位置変更 |
| 冬季にバッテリー性能が落ちる | 起動失敗、運用期間短縮 | 低温対応電池、容量余裕、断熱、冬季試験 |
| 結露・浸水 | 故障、画像不良 | 防水筐体、乾燥剤、通気膜、ケーブル処理 |
| 秘密情報漏洩 | S3/Slack 不正利用 | 最小権限、ローテーション、クラウド側通知化 |
| ソーラー不足 | 電池切れ | 日照見積もり、パネル大型化、撮影頻度調整 |
| 画像サイズ過大 | 通信時間増加、通信費増加 | 圧縮率調整、解像度調整、差分/サムネイル検討 |
