# システム構成案

## ゴール

1 日 1 回だけ屋外カメラ端末を起動し、写真を撮影して AWS S3 に保存し、撮影完了を Slack に通知する。通常時は可能な限り消費電力を抑え、バッテリー交換回数を減らす。

## 全体構成

```text
[屋外カメラ端末]
  ├─ RTC / 低消費電力タイマー
  ├─ マイコンまたは SBC
  ├─ カメラモジュール
  ├─ LTE/4G 通信モジュール + SIM
  ├─ バッテリー / ソーラー / 充電保護回路
  └─ 防水筐体 / アンテナ / 取付金具
        │
        │ LTE/4G
        ▼
[AWS]
  ├─ S3: 写真保存
  ├─ IAM: 最小権限の認証情報
  ├─ CloudWatch: ログ・メトリクス候補
  └─ Lambda/EventBridge: Slack 通知の代替案
        │
        ▼
[Slack]
  └─ Incoming Webhook または Slack API
```

## 端末側の動作フロー

1. RTC または低消費電力タイマーで 1 日 1 回起床する。
2. 電源制御 IC または MOSFET でカメラとローカル保存用ストレージへ給電する。
3. カメラで静止画を撮影する。
4. JPEG などの圧縮形式で、撮影時刻、端末 ID、電池電圧などのメタデータと一緒にローカルへ保存する。
5. 保存完了を確認してから、必要に応じてカメラの電源を停止する。
6. LTE モジュールへ給電し、初期化して回線接続を確立する。
7. 今回撮影分と、過去に未送信のローカル保存分を S3 にアップロードする。
8. Slack へ撮影結果、電池電圧、電波状況、S3 オブジェクトキー、未送信件数を通知する。
9. アップロード成功分を送信済みとしてマークし、失敗分はローカルに保持して次回起動時に再送する。
10. LTE モジュール、カメラ、ストレージを安全に停止し、端末を deep sleep または完全電源断に戻す。

### 撮影を LTE 接続より先に行う理由

LTE 接続前に撮影とローカル保存を完了させる方針にする。山間部や林間サイトでは電波状況により回線接続が失敗する可能性があるため、接続失敗時でも当日の写真を端末内に残し、後日再送または現地回収できるようにする。

この方針では、ローカル保存が単なる一時ファイルではなく、未送信データの保全領域になる。そのため、保存完了確認、ファイル破損対策、容量上限、古い未送信データの扱い、現地回収手順を設計対象に含める。

## クラウド連携方式の候補

### A. 端末から S3 と Slack へ直接送信

- 端末が S3 へ直接アップロードし、Slack Webhook へ直接通知する。
- 構成が単純だが、端末内にクラウド/Slack 認証情報を持つ必要がある。
- 低機能マイコンでは TLS、時刻同期、署名計算、再送処理が難しくなる可能性がある。

### B. 端末から AWS API へ送信し、AWS 側で Slack 通知

- 端末は S3 アップロードまたは AWS IoT Core/API Gateway への送信だけを行う。
- Slack 通知は Lambda が担当する。
- 端末に Slack Webhook URL を置かずに済み、通知フォーマット変更もクラウド側で対応しやすい。

### C. 端末から MQTT/HTTPS で中継 API へ送信

- 画像アップロード用のプリサインド URL を API から取得し、端末はその URL にアップロードする。
- 認証情報管理を簡素化できる可能性がある。
- API の実装・運用が追加で必要になる。

## 初期推奨アーキテクチャ

PoC では **B. 端末から AWS へ送信し、AWS 側で Slack 通知** を第一候補にする。

理由:

- Slack 認証情報を端末に持たせない。
- S3 イベント通知や Lambda により、通知処理を後から変更しやすい。
- 端末側は「撮影」と「アップロード」に集中できる。

## 電力設計の考え方

電池寿命は次の要素で大きく変わる。

- 待機時電流
- 起動時間
- LTE 接続確立時間
- アップロードに必要な送信時間
- 画像サイズ
- 電波状況
- 低温時のバッテリー性能低下
- ソーラー充電の有無と日照条件

初期段階では以下の測定を必須にする。

| 測定項目 | 目的 |
| --- | --- |
| deep sleep 電流 | 待機期間の消費電力を見積もる |
| 起動から撮影完了までの電流・時間 | カメラ処理の電力を見積もる |
| LTE 接続からアップロード完了までの電流・時間 | 通信処理の電力を見積もる |
| 低温時の起動可否 | 冬季キャンプ場での運用リスクを確認する |
| 電波弱環境での再送回数 | 山間部や林間サイトでの電力悪化を確認する |

## 未決定事項

- 設置場所の LTE キャリア別電波品質
- 必要な画角、解像度、夜間撮影要否
- ソーラーパネルを使うか、一次電池/二次電池のみで運用するか
- 運用目標期間（例: 1 か月、3 か月、1 年）
- 防水等級、耐候性、盗難/いたずら対策
